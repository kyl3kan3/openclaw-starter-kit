# Knowledge base prompts

## Ingest content

```
Ingest this content into my knowledge base.

Type: [article/video/pdf]
URL or attachment: [source]

Extract main topics, key takeaways, publication date, and metadata.
Store with vector embeddings for semantic search.
```

## Query knowledge base

```
Query my knowledge base: [question]

Return up to 5 results with source URLs and dates.
If nothing matches, say so clearly.
```

## Research topic

```
Research [TOPIC] using my knowledge base and optional web search.
Summarize existing knowledge, new developments, gaps, and sources to ingest.
```
